# 轨迹面板中文翻译 · 小白导读

> 把 DeepSeek Harness 的「轨迹面板」变成文科生也能看懂的样子：
> **全部翻译成中文 + 每一条轨迹配一句白话解释**，一看就懂。

---

## 🤔 这是什么？解决什么问题？

**先解释两个名词（写给非程序员）：**

- **DeepSeek Harness**：一个在你自己电脑上运行的 AI 工作台。它不只是聊天——它能读你的文件、改你的代码、运行命令、上网搜索，帮你真正"干活"。
- **轨迹面板**：AI 干活的"监控录像"。它逐条记录 AI 每一步做了什么：读了这个文件、跑了那条命令、搜索了那个网页、用了多少算力……相当于 AI 的"工作日志"。

**问题出在哪？**

轨迹面板本身非常有用，但它是给程序员设计的：满屏英文专业术语——`Tokens`、`TTFT`、`Tool Call`、`System Prompt`、`Compaction`……一个文科生打开它，就像看外星文字，完全不知道 AI 在干嘛，更不知道它干得对不对。

**这个工具就是来补上这一课的：**

它不改动 AI 的任何行为，只是把轨迹面板"翻译成人话"——术语变中文，每一行下面加一句大白话解释，顶部再给你一张"导读地图"，告诉你这个面板整体怎么看。

> 一句话：**它是轨迹面板的"中文说明书"。**

## ✨ 功能特性

| 功能 | 说明 |
|---|---|
| 🈶 **全中文标签** | `Turns`→按轮次、`Duration`→时长、`Tokens`→词元数、`TTFT`→首字延迟、`Turn 2`→第 2 轮……连数字单位都翻译 |
| 💡 **每条轨迹白话讲解** | 每一行下面自动加一句解释，例如「工具调用：AI 正在使用 read 工具：读取文件内容」 |
| 👋 **顶部导读横幅** | 打开面板先看到一张"阅读地图"：系统提示词是什么、用户消息在哪、工具调用怎么认 |
| 🔘 **翻译开关** | 横幅右下角「文/A 翻译」按钮，随时开/关；你的选择会被记住，刷新不丢 |
| 🧭 **不用记命令** | 安装一条命令，卸载一条命令，出错随时还原 |
| 🔒 **绝对安全** | 不联网、不上传任何数据、不改 AI 行为；只改一个界面文件（还自动备份原件） |

## 🚀 安装（一步一步来）

> **准备**：需要先安装好 DeepSeek Harness（本工具是给它的"界面美化补丁"，不是独立软件）。
> 全程只需要运行**一条命令**，其余都是复制粘贴。如果哪一步卡住，把提示发给会电脑的朋友，或发个 Issue，我会帮你看。

### 第 1 步：下载两个文件

把本仓库的 `patch.js` 和 `apply.sh` 两个文件放到同一个文件夹里
（点仓库页面的绿色 `Code` 按钮 → `Download ZIP` 也行）。

### 第 2 步：打开终端

- **Mac**：按 `Command + 空格`，输入"终端"，回车。
- **Windows**：先安装 [Git for Windows](https://git-scm.com/download/win)（一路"下一步"），然后右键桌面选 **Git Bash Here**。

### 第 3 步：进入文件所在文件夹

把上面那行（第一步里下载文件的路径）替换进去，回车：

```bash
cd /你的文件夹路径
```

> 小技巧：在终端里输入 `cd `（注意后面有个空格），然后把文件夹**直接拖进终端窗口**，再回车，就自动填好路径了。

### 第 4 步：运行安装命令（就这一条）

```bash
bash apply.sh
```

看到 `✅ 安装完成` 就成功了。它会自动找到 Harness 的轨迹面板文件、做备份、打上补丁。

### 第 5 步：刷新浏览器

回到 DeepSeek Harness 页面，**按 `F5`（或 `Command + R`）刷新**，打开任意会话 → 点顶部「轨迹」标签页——你会看到全新的中文面板。

## 🧪 怎么确认装好了？

打开「轨迹」面板后检查三件事：

1. 面板顶部出现带 ✨ chenshi.ai 署名和「文/A 翻译」按钮的**导读横幅**；
2. 每条轨迹下面出现 💡 **蓝色小字白话讲解**；
3. 英文标签全部变成中文。

以上都出现 = 安装成功 ✅

## 🛡️ 安全说明（重要，请放心）

- ✅ **纯本地运行**：不联网、不上传任何数据、不收集任何信息，全程在你自己的电脑上完成；
- ✅ **不动 AI 本身**：不改 AI 的行为、不碰你的文件，只是把"界面文字"翻译成中文；
- ✅ **自动备份**：安装时自动备份原文件（`client.js.bak`），任何时候都能一键还原；
- ✅ **随时可关**：点横幅上的「翻译：关」按钮，面板立即恢复英文原貌；
- ✅ **代码透明**：全部代码就一个 `patch.js`，几百行，任何人都可以检查，没有隐藏逻辑。

## ❓ 常见问题

**Q：升级 Harness 之后，翻译没了？**
A：正常。Harness 更新会覆盖补丁文件。重新下载 `patch.js` 和 `apply.sh` 再跑一次 `bash apply.sh` 即可（会自动识别并重新安装）。

**Q：我只想翻译，不想要讲解可以吗？**
A：目前开关是一起的。如果很多人想要"纯翻译模式"，可以在 Issue 里提，我加一个选项。

**Q：关掉翻译会影响 AI 干活吗？**
A：完全不会。它只是界面显示，AI 的工作过程一字不改。

**Q：Windows 可以用吗？**
A：可以，通过 Git Bash（见安装第 2 步）。如果你没有 Git Bash，也可以把补丁文件发给会用电脑的朋友帮忙运行一次。

**Q：这个补丁会过期吗？**
A：只要轨迹面板的界面结构不变就不会。Harness 大版本更新后如果发现翻译失效，请在 Issue 告诉我，我会更新适配。
